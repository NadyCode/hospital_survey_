# 病院向けオフライン・アンケートシステム

Windows デスクトップアプリケーション（Python + tkinter）

## 機能一覧

### 管理者モード（パスワード保護）
| 機能 | 詳細 |
|------|------|
| アンケート作成・編集 | 設問追加・削除・並び替え、全設問タイプ対応 |
| 設問タイプ | ラジオボタン・チェックボックス・ドロップダウン・短文テキスト・長文テキスト・評価スケール・部署氏名選択 |
| 必須項目設定 | 各設問を必須に設定可能、未入力時はバリデーションエラー |
| 分岐機能 | 特定の回答時に任意の設問へジャンプ |
| 表示条件 | 特定設問の回答によって設問を表示/非表示 |
| テストモード | 正解設定・配点・合格ライン設定 |
| 参照ファイル添付 | 設問にPDF等のローカルファイルへのリンクを貼付 |
| 職員マスター管理 | CSV インポート/エクスポート、部署・氏名の追加・編集・削除 |
| 集計・グラフ | 棒グラフ・円グラフの自動生成、PNG 画像エクスポート |
| 回答状況確認 | 回答済み/未回答者の一覧表示 |
| CSV エクスポート | 回答データを CSV 形式でエクスポート |
| アクセスログ | 端末名・IP・日時・操作モードのログ記録 |
| 設定 | 共有フォルダパス・パスワード変更 |

### 回答者モード
| 機能 | 詳細 |
|------|------|
| アンケート一覧 | 利用可能なアンケートから選択 |
| 部署・氏名連動 | 部署選択後に所属職員のみ氏名リストに表示 |
| 分岐回答 | 回答内容に応じて次の設問が動的に変化 |
| バリデーション | 必須項目の未入力をチェックして送信ブロック |
| 重複防止 | 同一ユーザーの重複回答をブロック（設定で解除可） |
| テスト結果表示 | 採点・正解表示・合否判定・円グラフ |

## ファイル構成

```
hospital_survey_/
├── main.py                    # エントリーポイント
├── config.py                  # アプリ設定
├── requirements.txt           # Python 依存パッケージ
├── build.bat                  # Windows EXE ビルドスクリプト
├── models/
│   ├── survey.py              # Survey / Question / BranchRule モデル
│   └── user.py                # 職員マスターモデル
├── utils/
│   ├── file_lock.py           # ファイル排他制御（ロックファイル方式）
│   ├── logger.py              # アクセスログ
│   └── data_manager.py        # 回答データ読み書き・集計
├── views/
│   ├── styles.py              # UI スタイル定義
│   ├── main_window.py         # トップ画面（モード選択）
│   ├── admin/
│   │   ├── login_dialog.py    # 管理者ログイン
│   │   ├── dashboard.py       # 管理者ダッシュボード
│   │   ├── survey_manager.py  # アンケート管理タブ
│   │   ├── survey_editor.py   # アンケート編集画面
│   │   ├── user_manager.py    # 職員マスター管理タブ
│   │   ├── aggregator.py      # 集計・グラフタブ
│   │   ├── access_log_tab.py  # アクセスログタブ
│   │   └── settings_tab.py    # 設定タブ
│   └── respondent/
│       ├── survey_form.py     # アンケート回答フォーム
│       └── result_view.py     # テスト結果表示
└── data/                      # 共有フォルダ（デフォルト）
    ├── master_user.csv        # 職員マスター
    ├── surveys/               # アンケート設定 JSON
    │   ├── survey_sample01.json
    │   └── survey_test01.json
    ├── answers_<survey_id>.csv # 回答データ
    └── access_log.csv          # アクセスログ
```

## 起動方法

```bash
pip install -r requirements.txt
python main.py
```

## Windows EXE 化

```bat
build.bat
```
`dist/HospitalSurvey/` フォルダに生成されます。

## 初期パスワード

管理者パスワード: `admin1234`
（管理者モード → 設定タブで変更可能）

## 非機能要件への対応

| 要件 | 実装 |
|------|------|
| インストール不要 | PyInstaller でポータブル exe 化可能 |
| 排他制御 | ロックファイル（.lock）方式で同時書き込みを防止 |
| 完全オフライン | インターネット接続不要 |
| 共有フォルダ対応 | 設定でパスを変更可能 |
